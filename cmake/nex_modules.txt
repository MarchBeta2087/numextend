# 每行一个模块，字段以 '|' 分隔，字段内以 ',' 分隔多项：
#   <module>|<deps>|<sources>|<public_headers>

# 子集构建时按依赖闭包展开（TODO §B2），故允许依赖成环
# （如 bigint_bin ↔ bigint_conv：bin 的十进制字符串快速路径调用 conv）。
#
# 本文件同时供 CMake（cmake/nex_modules.cmake）与 scripts/modules.py 使用，
# 是子集构建与子集文档生成的单一来源。
