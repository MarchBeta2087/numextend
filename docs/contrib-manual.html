nex_thread

nex_thread：contrib 层的跨平台线程池（pthread / Win32）。

设计边界（TODO §F）：

  • 不进入核心 libnex、不进 nex_modules.txt / amalgam / 子集闭包；
  • 调用方驱动：池由调用方创建/销毁，库内无全局状态、无锁；
  • 每个 job 由唯一 index 标识；job 之间必须相互独立（写不同输出）， 执行顺序与线程数不影响结果；
  • 错误传播由调用方负责（job 把错误写入自己的上下文）。

构建：-DNEX_ENABLE_THREAD=ON（默认 OFF），仅完整构建。

nex_parallel

nex_parallel_bin_mul_ntt：contrib 层的并行多模数 CRT NTT 乘法实验。

与核心 bigint_bin_mul 的关系：

  • 不修改核心；复用公开的 nex_ntt 与 bigint_bin 类型/API；
  • 强制使用双模数 CRT NTT（不按 Toom/NTT 阈值分派），要求 len(lhs)+len(rhs) ≤ 2^26（与核心 NTT 上限一致）；
  • 并行阶段：两个模数的 forward(a)/forward(b) 共 4 个独立 task， 点乘 2 个 task，逆变换 2 个 task；CRT/进位串行；
  • 结果与核心 NTT 路径逐位一致（同一模数、同一变换、同一 CRT）。

pool 为 NULL 时在调用线程顺序执行（用于对照/降级）。

nex_parallel_bin_mul_ntt

bigint_err_ty nex_parallel_bin_mul_ntt(bigint_bin_ty *dst, const bigint_bin_ty *lhs, const bigint_bin_ty *rhs, nex_thread_pool_ty *pool);

说明：并行多模数 CRT NTT 乘法：dst = lhs × rhs

参数

  • dst：目标（已初始化）
  • lhs/rhs：非负操作数；len(lhs)+len(rhs) ≤ 2^26
  • pool：线程池；NULL 表示在调用线程顺序执行

返回：BIGINT_OK_E / BIGINT_ERR_*（与核心乘法一致）

备注：结果与核心 NTT 路径逐位一致；不改变核心分派

nex_bigint_block

nex_bigint_block：contrib 层递归分块 NTT 乘法（P1b，issue #98）。

递归折半直到单块 max_len ≤ 2^26（直接 NTT 的 s ≤ 2^27）： a = a0 + a1·B^L, b = b0 + b1·B^L a·b = c0 + (sa·sb − c0 − c2)·B^L + c2·B^(2L) 其中 c0=a0·b0、c2=a1·b1、sa=a0+a1、sb=b0+b1；三个子积递归。 10^9 位约一层；10^10 位约四层（81 个基础积）。

限制：10^10 位的分块/SSA 内存模型约 64–114 GB；34 GB 机器会在 递归合并阶段 OOM（本实验实测）。更大规模需要 ≥256 GB 或 out-of-core。

参数

备注：结果精确；1e9 位实测 2403 s / 6.24 GB；1e10 位需 ≥256 GB 或 OOC

nex_ssa

nex_ssa：Schönhage–Strassen 原型（P1b-SSA，issue #102）。

参数：N bit → n=m=2^(k−1) 块、L=2n、环 Z/(2^L±1)；用两个环的循环 卷积 + CRT 恢复精确系数，再按 base 2^m 进位。 仅 contrib 实验；失败/规模过小时返回 UNSUPPORTED 或回退直接乘法。

说明：SSA 原型乘法：dst = lhs × rhs（仅 contrib 实验）

参数

  • dst：目标（已初始化；允许与 lhs/rhs 别名）
  • lhs/rhs：非负操作数

返回：BIGINT_OK_E；规模过小或环参数不支持时返回 BIGINT_ERR_UNSUPPORTED_E

备注：结果为精确值；1e6–1e8 位原型阶段，M2/M3 已冻结（TODO §K2）

nex_ooc

nex_ooc：out-of-core 分块乘法原型（P1b-OOC，issue #104）。

把操作数视为「肢文件」（小端 32-bit 肢序列，无头），按块长 L 切分：

a = Σ a_i·B^(iL)，b = Σ b_j·B^(jL)，B = 2^32 a·b = Σ_k B^(kL)·( Σ_{i+j=k} a_i·b_j )

输出按 k 升序生成：块 k 的累加器只保留 2L+2 肢，算完立即写盘，高位 作为进位带入块 k+1。因此峰值内存 O(L)，与操作数规模无关，代价是 每个 a_i / b_j 块被重复读取（块对总数 na·nb，I/O 约 O(n·nb)）。

与内存内算法（bigint_bin_mul / contrib/nex_bigint_block）逐位一致； 块对乘法直接复用核心 AUTO 分派（块内为 Karatsuba/Toom-3/CRT NTT）。

限制：M1 只用单线程顺序 I/O，未做块缓存、并行块对、块级 FFT；这些是 issue #104 的 M3 项。10^10 位的块数约 32（L=2^25 时），I/O 量约 数百 GB，需 M2 实测磁盘带宽。

nex_opencl

nex_opencl.h：contrib OpenCL 批量大整数实验（issue #98 P3）。

默认不构建；-DNEX_ENABLE_OPENCL=ON 时作为独立库 nex_opencl， 不进 libnex / amalgam / 子集闭包，也不改核心 API/ABI。

数据表示：调用方提供「按元素连续存放」的无符号大整数数组， 每个数固定 limbs 个 32-bit limb（小端），不足高位补零。 例：1000 位十进制 ≈ 104 limb（3328 bit）。

当前覆盖：

  • nex_opencl_madd：out[i] = a[i]*b[i] + c[i]（逐元素）
  • nex_opencl_dot ：out = Σ a[i]*b[i]（一批点积） 矩阵×矩阵子集见 nex_opencl_matmul_subset（M2，contrib/nex_opencl/README.md）。

说明：解包：从 count 个 limb 还原 bigint_bin，裁剪前导零并置正/零符号； v 须已用 bigint_bin_init()/init_cap() 初始化。返回 0 成功，-1 失败。
