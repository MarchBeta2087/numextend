## 观察

- 正确舍入超越函数的成本主要由 Ziv 迭代与级数阶数决定：1024 → 4096 bit
  约 25×，4096 → 16384 bit 约 20–25×；65536 bit 单次已达数十秒至数分钟。
- `log` 在 65536 bit 仍是最慢的一元实函数（约 221 s），`acos`/`atan2` 次之；
  复数 `log`/`tan` 约为对应实函数的 2–3 倍。
- 常数表达式中 `gamma_bm_2n` 最贵（n 翻倍 → 约 4× 项数）；Chudnovsky π
  在 65536 bit 仅约 0.11 s（整数定点，无正确舍入到浮点的开销）。
- 吞吐量表可用于估算容量：例如 4096 bit `bigfloat_log` ≈ 3.4 ops/s，
  1024 bit `bigfloat_mul` ≈ 1.18M ops/s。
