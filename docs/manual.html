Numextend 参考手册

Numextend（库前缀 nex）是一个纯 C99、零依赖的任意精度数值库，提供七种 数值类型与一张跨类型转换矩阵。

  • 整数：bigint_bin（二进制肢，基 2³²）、bigint_dec（十进制肢，基 10⁹）、 bigint_bin64（64 位肢变体）。
  • 有理数：bigfrac（既约分数）。
  • 浮点：bigfloat（二进制）、bigdecimal（十进制），精度与指数范围可调， 逐运算正确舍入。
  • 复数：bigcomplex_float、bigcomplex_decimal。

本手册面向使用者，说明每种类型的公开 API、语义与约定。 设计原理、算法与内部结构见仓库内 ../design.md。

兼容性：C99 为承诺基准，C11/C17/C23（及 C2y）实测通过；全部公开头文件带 extern "C"，C++11–C++26 可经 C ABI 直接链接。

顺序：简介 → 通用约定 → 安装与使用 → 示例 → API 参考（按类型）。 生成的 API 章节直接取自公开头文件的注释，是本手册的事实来源。

1. 简介与能力

Numextend 的目标是：在保持纯 C99、零外部依赖的前提下，提供一组语义严格 的任意精度数值类型——正确舍入、强异常安全（OOM 不破坏输出）、显式精度上下文。

1.1 能力总览

类型 主要能力
bigint_bin / bigint_dec 加减乘除（带余）、幂、模幂、gcd、移位、按位运算、整数平方根、字符串 I/O（进制 2..36）、比较与符号；bin ↔︎ dec 互转
bigint_bin64 64 位肢整数核心（加减乘、除法；用例见头文件）
bigfrac 精确有理数四则与约分、比较、与整数互转
bigfloat / bigdecimal 四则、sqrt、正确舍入、特殊值（±0/±∞/NaN）、分解/合成、字符串 I/O；bigdecimal 十进制 I/O 完全精确
bigcomplex_float / bigcomplex_decimal 加减乘除、共轭、模、相等
convert 七类型之间的精确/有损转换矩阵

1.2 设计取舍

  1. 正确性优先，其次可读性，再次性能；
  2. 无隐式精度：任何有损转换都必须显式传入目标精度上下文；
  3. 强异常安全：内存不足或非法参数时，输出参数保持调用前状态；
  4. 不做（v1 非目标）：SIMD/GPU/内部多线程、超越函数（仅保留 sqrt）、 次正规浮点、复数辐角 arg（依赖 atan）。

1.3 基本用法

#include "nex/bigint/bin/nex_bigint_bin.h"

bigint_bin_ty a, b, c;
bigint_bin_init(&a);
bigint_bin_init(&b);
bigint_bin_init(&c);
bigint_bin_from_u64(&a, 123456789U);
bigint_bin_from_u64(&b, 987654321U);
bigint_bin_mul(&c, &a, &b);       /* c = a × b，允许别名 */
/* ... 使用 c ... */
bigint_bin_free(&a);
bigint_bin_free(&b);
bigint_bin_free(&c);

每个值的生命周期遵循 _init → 运算 → _free；_move 可转移所有权， _copy 深拷贝。

1.4 语言与标准兼容性

  • C：默认以 C99 构建（项目承诺基准）；C11 / C17 / C23（及 C2y）实测通过。 可用 -DNEX_C_STANDARD=11/17/23 切换构建标准做验证。
  • C++：全部公开头文件带 extern "C" 守卫，C++11–C++26 可经 C ABI 直接 链接消费，无需包装或单独绑定。

C++ 中使用示例：

#include "nex/bigint/bin/nex_bigint_bin.h"

int main() {
    bigint_bin_ty a{};
    bigint_bin_init(&a);
    bigint_bin_from_u64(&a, 123456789u);
    /* ... */
    bigint_bin_free(&a);
    return 0;
}

2. 通用约定

本章约定适用于全部模块。

2.1 错误码

每个模块有自己的错误枚举（bigint_err_ty、bigfloat_err_ty、 bigdecimal_err_ty、bigfrac_err_ty、bigcomplex_*_err_ty 等），均以 *_OK_E = 0 表示成功，其余为错误。常见错误：

错误 含义
*_ERR_OOM_E 内存分配失败
*_ERR_INVALID_E 非法参数（空指针、非法进制等）
*_ERR_DIV_ZERO_E 除数为零
*_ERR_OVERFLOW_E 结果超出目标类型范围（如转 uint64_t）
*_ERR_PARSE_E 字符串解析失败
*_ERR_UNSUPPORTED_E 已登记但当前版本未实现

2.2 内存与 OOM（强异常安全）

任何因 OOM 或非法参数失败的运算，输出参数保持调用前的状态。因此可以在 已有对象上安全地重试或回退。示例：bigint_bin_mul(&c, &a, &b) 若返回 BIGINT_ERR_OOM_E，则 c 与调用前完全一致。

2.3 别名（aliasing）

算术函数的输出允许与任一输入别名，例如 bigint_bin_mul(&a, &a, &b) （就地累积）与 bigint_bin_mul(&a, &b, &a) 均合法。每个函数注释会注明是否 允许别名（本库算术函数普遍允许）。

2.4 线程安全

库内不加锁：同一对象不可被多线程并发访问；不同对象之间可并行使用。 调用方负责外部同步。

2.5 版本与 ABI

  • 库版本经 nex/nex_version.h 暴露（NEX_VERSION_MAJOR/MINOR/PATCH/STRING）， 与构建系统的 project(VERSION) 单一来源。
  • API 稳定性：1.x 只做向后兼容的增量。
  • ABI 稳定性：同一主版本内共享库可直接替换（SOVERSION = 主版本号）； 公开结构体的字段顺序/大小/对齐在同一主版本内冻结，但字段视为实现细节， 可移植代码应使用访问器而非依赖布局。

2.6 端序

实现基于 uint32_t/uint64_t 的值语义，预期与端序无关；当前仅在小端 平台（x86-64 / arm64）验证，大端未测试。

2.7 语言与标准兼容

公开头文件均以 extern "C" 包裹，因此同一套 API 既可由 C 也可由 C++ 直接 调用（C++11–C++26 经 C ABI 链接）。构建标准默认 C99，可经 NEX_C_STANDARD 切换（见 §3.1）。链接后语义与语言无关。

3. 安装与使用

3.1 构建与安装

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
      -DCMAKE_INSTALL_PREFIX=/your/prefix
cmake --build build --parallel
cmake --install build

安装内容：公开头文件、静态库、共享库（可选）、CMake 包配置与 pkg-config 文件。

  • 默认构建静态库；追加 -DBUILD_SHARED_LIBS=ON 构建共享库 （Linux/macOS 带 SOVERSION，如 libnex.so.1）。
  • 要求：C99 编译器（GCC / Clang / MSVC）与 CMake ≥ 3.16；默认标准 C99， 可用 -DNEX_C_STANDARD=11/17/23 切换验证。C++（11–26）可直接链接（§3.6）。

3.2 在 CMake 工程中使用

find_package(nex CONFIG REQUIRED)
target_link_libraries(app PRIVATE nex::nex)

配合 -DCMAKE_PREFIX_PATH=/your/prefix 指定安装位置。完整示例见仓库 examples/downstream/。C++ 工程同样使用 find_package(nex CONFIG REQUIRED) 与 nex::nex；公开头文件已带 extern "C"，无需额外包装。

3.3 使用 pkg-config

cc app.c $(pkg-config --cflags --libs nex) -o app

3.4 最小示例

#include "nex/bigint/bin/nex_bigint_bin.h"
#include "nex/nex_version.h"
#include <stdio.h>

int main(void) {
    bigint_bin_ty a, b, r;
    bigint_bin_init(&a);
    bigint_bin_init(&b);
    bigint_bin_init(&r);
    bigint_bin_from_str(&a, "123456789012345678901234567890", 10, NULL);
    bigint_bin_from_str(&b, "987654321098765432109876543210", 10, NULL);
    bigint_bin_mul(&r, &a, &b);

    size_t need = 0;
    bigint_bin_to_str(&r, 10, NULL, 0, &need);
    char *buf = (char *)malloc(need + 1);
    bigint_bin_to_str(&r, 10, buf, need, &need);
    printf("nex %s: %s\n", NEX_VERSION_STRING, buf);

    free(buf);
    bigint_bin_free(&r);
    bigint_bin_free(&b);
    bigint_bin_free(&a);
    return 0;
}

3.5 直接内嵌源码

库无外部依赖，也可直接 add_subdirectory(numextend) 并链接目标 nex， 无需安装。

3.6 在 C++ 中使用

公开头文件均带 extern "C" 守卫，C++ 直接包含即可：

#include "nex/bigint/bin/nex_bigint_bin.h"

int main() {
    bigint_bin_ty a{};
    bigint_bin_init(&a);
    /* ... */
    bigint_bin_free(&a);
    return 0;
}

无需 extern "C" 包装或单独的语言绑定；库本身可继续以 C 编译，C++ 消费者 经 C ABI 链接（已由 tests/test_cpp_consumer.cpp 回归）。

4. 示例

本章给出各类型的短示例；完整演示见仓库 demo/demo.c。

4.1 大整数：阶乘与十进制 I/O

bigint_bin_ty f, i;
bigint_bin_init(&f);
bigint_bin_init(&i);
bigint_bin_from_u64(&f, 1);
for (unsigned k = 1; k <= 100; k++) {
    bigint_bin_from_u64(&i, k);
    bigint_bin_mul(&f, &f, &i);      /* f *= i */
}
/* f = 100!，可经 bigint_bin_to_str 输出 */

4.2 带方法选择的乘法

bigint_mul_method_ty m;

bigint_bin —— 二进制肢任意精度整数

bigint_bin_ty：二进制肢（基 2^32）任意精度整数（设计文档 §4）。

  • 最高有效肢 limbs[len-1] != 0；

  • 负数位运算按二进制补码的无限符号扩展解释（与 Python 一致）， 例如 -1 & x == x。

bigint_bin64 —— 64 位肢任意精度整数

nex_bigint_bin64：64 位肢二进制大整数（设计文档 §13 #3"64 位肢变体"）。

与 bigint_bin 平行：基 2^64、小端序、同一规范化不变式（最高有效肢非零； 零 ⇔ len == 0 且 sign == ZERO_E）与错误码枚举（bigint_err_ty）。

64 位肢的意义：同一位长下肢数减半，加法 / 减法 / schoolbook 乘法的 循环次数减半（实测 ~2 倍提速，见 bench）。代价是乘法的 64×64→128 中间量——C99 无 128 位扩展，经编译器探测条件编译（§13 #3）：

  • GCC / Clang：SIZEOF_INT128 可用时走硬件 128 位乘法；
  • MSVC 及其他：回退便携 32 位半字 4 乘（nex_u128_mul 的 portable 路径）。

本模块为独立变体，不参与 bigint_bin / bigint_dec 的互转与字符串 I/O （v1 仅提供 加减乘 与基本转换，其余按需扩展）。

bigfloat —— 可调精度二进制浮点

bigfloat_ty：可调精度二进制浮点数（设计文档 §7）。

语义模型：

  • 正常值：value = (−1)^sign × mant × 2^exp，mant 为正整数且最高位恒 1 （IEEE 754 隐藏位显式化），exp 为二进制指数；
  • 特殊值：+0 / −0 / +∞ / −∞ / NaN，由 flag 独立表达；
  • mant 的符号字段恒为 BIGINT_SIGN_POS_E（正常值）或 BIGINT_SIGN_ZERO_E （特殊值），符号完全由 flag 表达，避免双重符号源；
  • 正常值表示唯一：给定"最高位恒 1"规范化要求，数值到 (mant, exp) 是双射。

常量约定：

  • BIGFLOAT_MAX_EXP_BITS 限制 exp_bits 上界，防止 ctx 构造时指数范围溢出。

七标志：±0 / 正常值 / ±∞ / NaN

typedef enum {
BIGFLOAT_POS_ZERO_E = 0,  // +0

BIGFLOAT_POS_E,           // 正（正常值）
BIGFLOAT_NEG_E,           // 负（正常值）
BIGFLOAT_POS_INF_E,       // 正无穷

bigdecimal —— 可调精度十进制浮点

bigdecimal_ty：可调精度十进制浮点数（设计文档 §8）。

语义模型：

  • 正常值：value = (−1)^sign × mant × 10^exp，mant 为正整数且 个位非 0（规范化：无尾随十进制零），exp 为十进制指数；
  • 特殊值：+0 / −0 / +∞ / −∞ / NaN，由 flag 独立表达；
  • 表示唯一：给定"无尾随零"规范化要求，数值到 (mant, exp) 是双射 （与 bigfloat 的"最高位恒 1"平行，§8.1）。

  • BIGDECIMAL_MAX_EXP_DIGITS 限制 exp_digits 上界，保证 ±(10^exp_digits − 1) 不溢出 int64（10^18 − 1 < INT64_MAX）。

ntt —— 数论变换核心（低层）

nex_ntt：数论变换（NTT）核心模块（设计文档 §4.3）。

本模块是 bin / dec 乘法分派共用的只读公共算法模块：只操作系数数组 （uint32_t * + 长度），不依赖任何 bigint 类型，无动态分配。

关键约定：

  • 模数一律为形如 p = k·2^c + 1 的素数（k 奇），内置表见 ntt_mod_get()， c 覆盖 21..27。选取模数组合须满足：每个模数 2^c ≥ N，且 Πp > C （C 为卷积系数上界，见设计文档 §4.3）；
  • 变换长度 N = 2^log2n（须 log2n ≤ mod->c）；正变换用 DIF（频域抽取， Gentleman–Sande）蝶形、逆变换用 DIT（时域抽取，Cooley–Tukey）蝶形， 正逆配对后输入输出均为自然序，无需位反转（设计文档 §4.3）；
  • 逆变换末尾乘以 N^-1 mod p 归一化；
  • 本模块所有函数无全局可变状态、线程安全（设计文档 §3.3）；
  • 传入的 mod 必须已通过 ntt_mod_validate() 校验（内置表天然合法）。

nex_alloc —— 内部统一分配器

nex_alloc：库内统一分配器抽象（内部使用）。

目的：

  1. 归一化分配入口，供 OOM 注入测试（设计 §12"错误路径注入失败分配 验证清理路径"）：nex_test_alloc_fail_after 设为 N 时，第 N 次及 之后的分配返回 NULL（0 = 立即失败；SIZE_MAX = 不失败，默认）；
  2. 为后续自定义分配器钩子（§13 后续方向）预留单一入口。

语义：

  • nex_malloc / nex_realloc 失败返回 NULL（与标准库一致）；realloc 失败时原指针仍有效（调用方须保证该模式下的状态一致性，即 OOM 时 输出参数不变——库内 ensure_cap 等均遵循）；
  • 计数器仅在库内部可见，测试经公开函数 nex_test_alloc_fail_after 直接设置（头文件内声明，测试包含本头文件即可）。

分配失败注入计数器（SIZE_MAX = 不注入，默认）。测试直接赋值。
